# Breast Cancer Classification using Machine Learning

## Project Overview
This project uses Machine Learning to classify breast cancer tumors as malignant or benign using the Breast Cancer Wisconsin dataset.

The model was trained using a Random Forest Classifier and achieved more than 95% test accuracy.

---

## Objective
To build a reliable classification model for detecting breast cancer using medical diagnostic features.

---

## Dataset
Dataset: Breast Cancer Wisconsin Dataset

Features include:
- Radius
- Texture
- Perimeter
- Area
- Smoothness
- Compactness
- Symmetry
- Fractal Dimension
and more.

Target:
- Malignant (Cancerous)
- Benign (Non-cancerous)

---

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

---

## Machine Learning Model
Model Used:
- Random Forest Classifier

Hyperparameters:
- n_estimators = 200
- max_depth = 10
- random_state = 42

---

## Project Workflow
1. Upload Dataset
2. Data Cleaning
3. Feature Selection
4. Train-Test Split (80-20 Stratified)
5. Model Training
6. Prediction
7. Accuracy Evaluation
8. Confusion Matrix
9. Feature Importance Analysis

---

## Results
- Test Accuracy: 95%+
- Low Train-Test Gap
- Good Generalization Performance

---

## Output Visualizations
- Confusion Matrix
- Feature Importance Graph

---

## Conclusion
The Random Forest model successfully classified breast cancer tumors with high accuracy and strong performance on unseen data.
